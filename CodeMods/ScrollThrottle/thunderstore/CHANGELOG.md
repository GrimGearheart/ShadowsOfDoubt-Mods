# Changelog

## 1.1.1

- Added a "Safe to remove?" note to the description. No changes to the mod itself.

## 1.1.0
- Removed the middle-click reset: middle mouse is the game's flashlight toggle. Existing configs using it are switched to no reset key (you can set another key).
- Added a notch at 100%: scrolling through normal speed stops there, so a quick flick always returns you to normal.

## 1.0.0
- Initial release: mouse-wheel movement throttle (20%–150%), middle-click reset, on-screen notification, configurable range, step, modifier key and walk-only mode.
