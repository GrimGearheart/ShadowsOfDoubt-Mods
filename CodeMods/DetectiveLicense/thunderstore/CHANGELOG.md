# Changelog

## 1.2.0

- New: **public records** for license holders. Ask a City Hall clerk to check the public records and they'll give you their computer login; the lobby computers then have the citizen database (the same one as the Enforcer offices). Each printout costs 50 crows (`Records.PrintCost`). Without a license the clerk turns you away.
- Fixed: mod conversation options (from this mod and Sanitation Department) could all disappear after loading a second save without restarting the game.

## 1.1.2

- Added a note that the mod is made with the help of AI. No changes to the mod itself.

## 1.1.1

- Added a "Safe to remove?" note to the description and a link to the source code. No changes to the mod itself.

## 1.1.0
- New: a Credentials card on the pause menu shows your license and any crime scene permits still running, with the time left. Shared with The Protectorate's other mods: Sanitation Department adds its own section to the same card.

## 1.0.0
- Initial release: Crime Scene Permit (100 crows, 4 hours) and Private Investigator License (1,500 crows, permanent) sold at City Hall. Covers open murder cases (murder site and victim's home); the license also improves "Can I come in and take a look around?" odds.
